|---|---|
| *(didascalia)* | To them enter COUNT TERTSKY. |
| COUNTESS | — Tertsky!<br>What ails him? What an image of affright!<br>He looks as he had seen a [[Ghost\|ghost]]. |
| *(didascalia)* | Tertsky leading Wallenstein aside. |
| TERTSKY | Is it thy command that all<br>the Croats — |
| WALLENSTEIN | Mine! |
| TERTSKY | We are betrayed. |
| WALLENSTEIN | What? |
| TERTSKY | They are off! This [[Night\|night]]<br>The Jägers likewise — all the villages<br>In the whole round are empty. |
| WALLENSTEIN | Isolani? |
| TERTSKY | Him thou hast sent away. Yes, surely. |
| WALLENSTEIN | I? |
| TERTSKY | No! Hast thou not sent him off? Nor Deodate?<br>They are vanished both of them. |
