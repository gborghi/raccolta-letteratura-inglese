| *(didascalia)* | Enter [[Arcite]] with a bundle containing meat, wine, and |
| *(didascalia)* | files |
| [[Arcite|ARCITE]] | I should be near the place. Ho, cousin Patamon! |
| *(didascalia)* | Enter [[Palamon]] as from the bush |
| [[Palamon|PALAMON]] | [[Arcite]]. |
| [[Arcite|ARCITE]] | The same. I have brought you food and files. Come forth and [[Fear|fear]] not, here’s no [[Theseus]]. |
| [[Palamon|PALAMON]] | Nor none so honest, [[Arcite]]. |
| [[Arcite|ARCITE]] | That’s no matter—We’ll argue that hereafter. Come, take [[Courage|courage]]—<br>You shall not die thus beastly. Here, sir, drink;<br>I know you are faint. Then I’ll talk further with you. |
| [[Palamon|PALAMON]] | [[Arcite]], thou mightst now [[Poison|poison]] me. |
| [[Arcite|ARCITE]] | I might—But I must [[Fear|fear]] you first. Sit down and, good now,<br>No more of these vain parleys. Let us not,<br>Having our ancient reputation with us,<br>Make talk for fools and cowards. To your health, sir. |
| [[Palamon|PALAMON]] | Do. |
| *(didascalia)* | [[Arcite]] drinks |
| [[Arcite|ARCITE]] | Pray sit down, then, and let me entreat you, By all the honesty and [[Honour|honour]] in you, No mention of this woman—’twilt disturb us. We shall have [[Time|time]] enough. |
| [[Palamon|PALAMON]] | [[Well]], sir, I’ll pledge you.<br>[[Palamon]] drinks |
| [[Arcite|ARCITE]] | Drink a good hearty draught; it breeds good [[Blood|blood]],<br>man.<br>Do not you feel it thaw you? |
| [[Palamon|PALAMON]] | Stay, I’ll tell you<br>After a draught or two more.<br>[[Palamon]] drinks |
| [[Arcite|ARCITE]] | Spare it not—<br>The Duke has more, coz. Eat now. |
| [[Palamon|PALAMON]] | Yes.<br>[[Palamon]] eats |
| [[Arcite|ARCITE]] | I am glad<br>You have so good a stomach. |
| [[Palamon|PALAMON]] | I am gladder<br>I have so good meat to’t. |
| [[Arcite|ARCITE]] | Is’t not mad, lodging Here in the wild woods, cousin? |
| [[Palamon|PALAMON]] | Yes, for them<br>That have wild consciences. |
| [[Arcite|ARCITE]] | How tastes your victuals?<br>Your hunger needs no sauce, I see. |
| [[Palamon|PALAMON]] | Not much.<br>But if it did, yours is too tart, sweet cousin.<br>What is this? |
| [[Arcite|ARCITE]] | Venison. |
| [[Palamon|PALAMON]] | ’Tis a lusty meat—<br>Give me more wine. Here, [[Arcite]], to the wenches |
| *(didascalia)* | We have known in our days. Drinking The lord |
| [[Palamon|PALAMON]] | steward’s daughter.<br>Do you remember her? |
| [[Arcite|ARCITE]] | After you, coz. |
| [[Palamon|PALAMON]] | She loved a black-haired man. |
| [[Arcite|ARCITE]] | She did so; [[Well|well]], sir. |
| [[Palamon|PALAMON]] | And I have heard some call him [[Arcite]], and— |
| [[Arcite|ARCITE]] | Out with’t, [[Faith|faith]]. |
| [[Palamon|PALAMON]] | She met him in an arbour—<br>What did she there, coz? Play o’th’ virginals? |
| [[Arcite|ARCITE]] | Something she did, sir— |
| [[Palamon|PALAMON]] | Made her groan a month for’t—<br>Or two, or three, or ten. |
| [[Arcite|ARCITE]] | The marshal’s sister Had her share too, as I remember, cousin,<br>Else there be tales abroad. You’ll pledge her? |
| [[Palamon|PALAMON]] | Yes. |
| *(didascalia)* | They drink |
| [[Arcite|ARCITE]] | A pretty brown wench ’tis. There was a [[Time|time]]<br>When young men went a-hunting, and a wood,<br>And a broad beech, and thereby hangs a tale—<br>Heigh-ho! |
| [[Palamon|PALAMON]] | For Emily, upon my life! [[Fool]],<br>Away with this strained mirth. I say again,<br>That sigh was breathed for Emily. Base cousin,<br>Dar’st thou break first? |
| [[Arcite|ARCITE]] | You are wide. |
| [[Palamon|PALAMON]] | By heaven and earth,<br>There’s nothing in thee honest. |
| [[Arcite|ARCITE]] | Then I’ll leave you—<br>You are a beast now. |
| [[Palamon|PALAMON]] | As thou mak’st me, traitor. |
| [[Arcite|ARCITE]] | (pointing to the bundle)<br>There’s all things needful: files and shirts and<br>perfumes—<br>I’ll come again some two hours hence and bring<br>That that shall quiet all. |
| [[Palamon|PALAMON]] | A [[Sword|sword]] and armour. |
| [[Arcite|ARCITE]] | [[Fear]] me not. You are now too foul. Farewell.<br>Get off your trinkets: you shall want naught. |
| [[Palamon|PALAMON]] | Sirrah— |
| [[Arcite|ARCITE]] | I’ll hear no more. |
| *(didascalia)* | Exit |
| [[Palamon|PALAMON]] | If he keep touch, he dies for’t. |
| *(didascalia)* | Exit as into the bush |
