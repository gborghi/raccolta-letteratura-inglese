| *(didascalia)* | Enter Arcite with a bundle containing meat, wine, and |
| *(didascalia)* | files |
| ARCITE | I should be near the place. Ho, cousin Patamon! |
| *(didascalia)* | Enter Palamon as from the bush |
| PALAMON | Arcite. |
| ARCITE | The same. I have brought you food and files. Come forth and fear not, here’s no Theseus. |
| PALAMON | Nor none so honest, Arcite. |
| ARCITE | That’s no matter—We’ll argue that hereafter. Come, take courage—<br>You shall not die thus beastly. Here, sir, drink;<br>I know you are faint. Then I’ll talk further with you. |
| PALAMON | Arcite, thou mightst now poison me. |
| ARCITE | I might—But I must fear you first. Sit down and, good now,<br>No more of these vain parleys. Let us not,<br>Having our ancient reputation with us,<br>Make talk for fools and cowards. To your health, sir. |
| PALAMON | Do. |
| *(didascalia)* | Arcite drinks |
| ARCITE | Pray sit down, then, and let me entreat you, By all the honesty and honour in you, No mention of this woman—’twilt disturb us. We shall have time enough. |
| PALAMON | Well, sir, I’ll pledge you.<br>Palamon drinks |
| ARCITE | Drink a good hearty draught; it breeds good blood,<br>man.<br>Do not you feel it thaw you? |
| PALAMON | Stay, I’ll tell you<br>After a draught or two more.<br>Palamon drinks |
| ARCITE | Spare it not—<br>The Duke has more, coz. Eat now. |
| PALAMON | Yes.<br>Palamon eats |
| ARCITE | I am glad<br>You have so good a stomach. |
| PALAMON | I am gladder<br>I have so good meat to’t. |
| ARCITE | Is’t not mad, lodging Here in the wild woods, cousin? |
| PALAMON | Yes, for them<br>That have wild consciences. |
| ARCITE | How tastes your victuals?<br>Your hunger needs no sauce, I see. |
| PALAMON | Not much.<br>But if it did, yours is too tart, sweet cousin.<br>What is this? |
| ARCITE | Venison. |
| PALAMON | ’Tis a lusty meat—<br>Give me more wine. Here, Arcite, to the wenches |
| *(didascalia)* | We have known in our days. Drinking The lord |
| PALAMON | steward’s daughter.<br>Do you remember her? |
| ARCITE | After you, coz. |
| PALAMON | She loved a black-haired man. |
| ARCITE | She did so; well, sir. |
| PALAMON | And I have heard some call him Arcite, and— |
| ARCITE | Out with’t, faith. |
| PALAMON | She met him in an arbour—<br>What did she there, coz? Play o’th’ virginals? |
| ARCITE | Something she did, sir— |
| PALAMON | Made her groan a month for’t—<br>Or two, or three, or ten. |
| ARCITE | The marshal’s sister Had her share too, as I remember, cousin,<br>Else there be tales abroad. You’ll pledge her? |
| PALAMON | Yes. |
| *(didascalia)* | They drink |
| ARCITE | A pretty brown wench ’tis. There was a time<br>When young men went a-hunting, and a wood,<br>And a broad beech, and thereby hangs a tale—<br>Heigh-ho! |
| PALAMON | For Emily, upon my life! Fool,<br>Away with this strained mirth. I say again,<br>That sigh was breathed for Emily. Base cousin,<br>Dar’st thou break first? |
| ARCITE | You are wide. |
| PALAMON | By heaven and earth,<br>There’s nothing in thee honest. |
| ARCITE | Then I’ll leave you—<br>You are a beast now. |
| PALAMON | As thou mak’st me, traitor. |
| ARCITE | (pointing to the bundle)<br>There’s all things needful: files and shirts and<br>perfumes—<br>I’ll come again some two hours hence and bring<br>That that shall quiet all. |
| PALAMON | A sword and armour. |
| ARCITE | Fear me not. You are now too foul. Farewell.<br>Get off your trinkets: you shall want naught. |
| PALAMON | Sirrah— |
| ARCITE | I’ll hear no more. |
| *(didascalia)* | Exit |
| PALAMON | If he keep touch, he dies for’t. |
| *(didascalia)* | Exit as into the bush |
