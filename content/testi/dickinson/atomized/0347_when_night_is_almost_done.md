<span class="atom-split" data-atom="0347_when_night_is_almost_done" data-title="347. When Night is almost done —" data-chapter="" data-kind="intro"></span>


When [[Night]] is almost done —  
And Sunrise grows so near  
That we can touch the Spaces —  
It's [[Time|time]] to smooth the Hair —  

And get the Dimples ready —  
And [[Wonder|wonder]] we could care  
For that old — faded Midnight —  
That frightened — but an Hour —
