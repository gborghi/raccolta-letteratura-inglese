<span class="atom-split" data-atom="0120_if_this_is_fading" data-title="120. If this is &quot;fading&quot;" data-chapter="" data-kind="intro"></span>


If this is "fading"  
Oh let me immediately "fade"!  
If this is "dying"  
Bury me, in such a shroud of red!  
If this is "[[Sleep|sleep]],"  
On such a [[Night|night]]  
How proud to shut the eye!  
Good Evening, gentle Fellow men!  
Peacock presumes to die!


<span class="qlang-split" data-lang="it"></span>

Se questo è "svanire"  
Oh lasciatemi subito "svanire"!  
Se questo è "morire"  
Seppellitemi, in un tale sudario di rosso!  
Se questo è "[[Sleep|sonno]],"  
In una simile [[Night|notte]]  
Che orgoglio chiudere l'occhio!  
Buona Sera, gentili miei Simili!  
Il Pavone presume di morire!
