| *(didascalia)* | To them enter ILLO. |
| ILLO | Has Tertsky told thee? |
| TERTSKY | He knows all. |
| ILLO | And likewise<br>That Esterhatzy, Goetz, Maradas, Kaunitz,<br>Kolatto, Palfi, have forsaken thee? |
| TERTSKY | Damnation! |
| WALLENSTEIN | *(winks at them)* Hush! |
| COUNTESS | *(who has been watching them anxiously from the distance and now advances to them)* Tertsky! Heaven! What is it? What<br>has happened? |
| WALLENSTEIN | *(scarcely suppressing his emotions)* Nothing! let us<br>be gone! |
| TERTSKY | *(following him)* Theresa, it is nothing. |
| COUNTESS | *(holding him back)* Nothing? Do I not see, that all the<br>lifeblood<br>Has left your cheeks — look you not like a [[Ghost\|ghost]]?<br>That even my brother but affects a calmness? |
| *(didascalia)* | Page (enters). An Aid-de-Camp enquires for the Count Tertsky. |
| *(didascalia)* | [TERTSKY follows the Page. |
| WALLENSTEIN | Go, hear his business. *(To ILLO.)* This could not have happened<br>So unsuspected without mutiny.<br>Who was on guard at the gates? |
| ILLO | 'Twas Tiefenbach. |
| WALLENSTEIN | Let Tiefenbach leave guard without delay,<br>And Tertsky's grenadiers relieve him. *(ILLO is going.)* Stop!<br>Hast thou heard aught of Butler? |
| ILLO | Him I met.<br>He will be here himself immediately.<br>Butler remains unshaken. |
| *(didascalia)* | [ILLO exit. WALLENSTEIN is following him. |
| COUNTESS | Let him not leave thee, sister! go, detain him!<br>There's some misfortune. |
| DUCHESS | *(clinging to him)* Gracious heaven! What is it? |
| WALLENSTEIN | Be tranquil! leave me, sister! dearest wife!<br>We are in camp, and this is nought unusual;<br>Here [[Storm\|storm]] and sunshine follow one another<br>With rapid interchanges. These fierce spirits<br>Champ the curb angrily, and never yet<br>Did quiet bless the temples of the leader.<br>If I am to stay, go you. The plaints of women<br>Ill suit the scene where men must act. |
| *(didascalia)* | [He is going: TERTSKY returns. |
| TERTSKY | Remain here. From this [[Window\|window]] must we see it. |
| WALLENSTEIN | *(to the Countess)* Sister, retire! |
| COUNTESS | No — never. |
| WALLENSTEIN | 'Tis my will. |
| TERTSKY | *(leads the Countess aside, and drawing her attention to the Duchess)* Theresa! |
| DUCHESS | Sister, come! since he commands it. |
