# 599. There is a pain — so utter —

*by Dickinson*  ·  **Cluster:** [[Melancholy · Suffering · Pain and Suffering]]

> [!abstract] 
> A definition of pain so total it swallows substance and covers the abyss with trance so memory can cross it safely. Themes of pain, suffering, and psychic survival.

## Connections

**Themes & Concepts:** [[Pain and Suffering]], [[Suffering]], [[Melancholy]], [[Self-Knowledge]], [[Memory and Time]]

## Testo integrale / Full text

There is a pain — so utter — 
It swallows substance up — 
Then covers the Abyss with Trance — 
So Memory can step 
Around — across — upon it — 
As one within a Swoon — 
Goes safely — where an open eye — 
Would drop Him — Bone by Bone.
