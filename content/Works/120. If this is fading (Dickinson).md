# 120. If this is "fading"

*by Dickinson*  ·  **Cluster:** [[Death · Mortality · Immortality]]

> [!abstract] 
> A lyric making the autumn leaf's death gorgeous: if this red fading is dying, the speaker would die proudly; death as a splendid, peacock-proud, willing sleep.
