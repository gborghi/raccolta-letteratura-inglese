# 1508. You cannot make Remembrance grow

*by Dickinson*  ·  **Cluster:** [[Memory and Time · Memory · Nostalgia]]

> [!abstract] 
> An aphoristic lyric using horticultural imagery to argue that genuine memory is rooted, indestructible (shod with adamant), and cannot be artificially cultivated or cut down.
