# 802. Time feels so vast that were it not

*by Dickinson*  ·  **Cluster:** [[Death · Mortality · Immortality]]

> [!abstract] 
> A metaphysical epigram fearing that time's vast circumference would engross finitude were it not for eternity, which prepares the soul for a stupendous vision. Sets time against eternity and immortality.
