# 1253. Had this one Day not been.

*by Dickinson*  ·  **Cluster:** [[Memory and Time · Memory · Nostalgia]]

> [!abstract] 
> A single cherished day measured against loss; how love values what loss would value more, memory and transience.

## Testo integrale / Full text

Had this one Day not been. 
Or could it cease to be 
How smitten, how superfluous, 
Were every other Day! 
 
Lest Love should value less 
What Loss would value more 
Had it the stricken privilege, 
It cherishes before.
